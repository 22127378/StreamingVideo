# 📺 StreamForge - Web Frontend

Giao diện Web Player và Dashboard quản lý video trực quan, hiện đại.

## Tính năng chính (Sắp triển khai ở Feature 4):
- Giao diện Dark Mode cao cấp với Glassmorphism.
- Upload video trực tiếp từ trình duyệt lên S3 qua Presigned URL (hiển thị tiến trình % realtime).
- Theo dõi trạng thái Transcode trực tiếp.
- Trình phát Video HLS mượt mà tích hợp bộ chọn chất lượng (Quality Selector: Auto, 1080p, 720p, 480p).
- Mô phỏng tính năng Playback có phân quyền (Tier-gated: Free vs VIP).
